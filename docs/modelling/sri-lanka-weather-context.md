# Sri Lanka Weather Context

Kunatu should be built around Sri Lankan weather realities rather than imported generic weather-app patterns.

## Context To Model

- Monsoon seasonality.
- Coastal weather differences.
- Hill country rainfall patterns.
- Urban flood sensitivity.
- Heat and humidity discomfort.
- Fisher, commuter, farmer, and event-planning use cases.

## Advisory Caution

Public warnings should not compete with official disaster or meteorological warnings unless the system can clearly distinguish unofficial advisory context from official alerts.

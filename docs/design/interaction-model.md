# Interaction Model

The first usable Kunatu interface should answer a practical question quickly: what is happening around me, what may happen soon, and how confident is that forecast?

## Primary Flow

1. Detect or select location.
2. Show current/observed conditions.
3. Show near-term forecast and confidence.
4. Allow layer toggles for rain, cloud, wind, heat, and uncertainty.
5. Explain what the user should watch next.

## Mobile Shape

- Map or atmosphere fills the background.
- Bottom sheet carries current conditions and forecast detail.
- Layer controls remain reachable by thumb.
- Advisory language stays short and plain.

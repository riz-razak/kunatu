# Prototype Brief

The first design prototype should test whether Kunatu can communicate weather intelligence without overwhelming the user.

## Prototype Screens

- Home/current weather.
- Rain layer active.
- Wind layer active.
- Forecast uncertainty panel.
- Advisory panel.
- Language-ready layout stress test.

## Prototype Questions

- Can users distinguish observed rain from forecast rain?
- Does the atmosphere layer clarify or distract?
- Can uncertainty be understood without technical language?
- Does the design work on a low-end mobile screen?

# Visual Language

Kunatu should look like weather intelligence for an island, not a generic dashboard.

## Direction

- Bawa Earth public surface: `#FAFAF8` light base, `#E5E1DA` borders, `#1A1A2E` text.
- Yan green (`#2D6A4F`) for trust, operating state, and primary actions.
- Water blue (`#3B7EA1`) for rain, forecast, and map/weather layers.
- Gold (`#C4A35A`) for caution and humidity/heat emphasis.
- Red (`#B8340B`) only for evidence-backed severe states.
- Layered depth: map, atmosphere, advisory panels.
- Typography that supports English now and Sinhala/Tamil later.

## Avoid

- Generic SaaS cards as the dominant visual language.
- Decorative particles that imply false data.
- Alarmist red warning states without evidence.
- Dark-mode/glassmorphism treatment for the public Yan surface.
- Desktop-first layouts.

# Visual Language

Kunatu should look like weather intelligence for an island, not a generic dashboard.

## Direction

- Dark atmospheric base.
- Cyan/teal light for rain, radar, and active weather.
- Warm accents only for heat, humidity, or warning contrast.
- Layered depth: map, atmosphere, advisory panels.
- Typography that supports English now and Sinhala/Tamil later.

## Avoid

- Generic SaaS cards as the dominant visual language.
- Decorative particles that imply false data.
- Alarmist red warning states without evidence.
- Desktop-first layouts.
